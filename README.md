## How to run

Requirements: Python 3.10+, numpy, pandas, matplotlib
pip install numpy pandas matplotlib

Keep all files in the same folder:
fishing.py, agents.py, experiment.ipynb, task3.py,
fishing_log_ioni.json, fishing_log_szabo.json, fishing_log_kimj.json

Tasks 4-6: open experiment.ipynb and run Kernel > Restart & Run All (about 1 minute).
Task 3: python task3.py (about 1 minute; prints the metric check, the 1000-bay
experiment and the team tables used in the report)

Player names: ioni (Bianca), szabo (Andreea), kimj (Jieun).
